Box Model Exploration

Every element is made of four nested layers.

MARGIN
BORDER
PADDING
CONTENT

Content: the text or media inside the element.

Padding: space between content and border.

Border: the visible edge around padding.

Margin: space outside the border.

Default box sizing
Width: 220px + padding + border
