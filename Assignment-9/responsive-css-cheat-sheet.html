Responsive CSS Cheat Sheet

Quick notes for building flexible websites.

Filters

Change how images look using blur(), grayscale(), sepia() and more.

img { filter: grayscale(1); }

Media Queries

Apply styles only when a screen matches a condition.

@media (max-width: 700px) { ... }

Responsive Design

Use fluid layouts and flexible media to fit many screens.

width: min(100%, 900px);

Typography

Scale text with relative units and clamp().

font-size: clamp(1rem, 2vw, 1.5rem);
