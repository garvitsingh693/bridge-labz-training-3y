Responsive Design

Responsive design lets a page adapt to different screen sizes. Grid, Flexbox, flexible images and media queries help content remain useful on phones, tablets and desktops.

Quick Cheat Sheet

  • Use flexible widths.
  • Set images to max-width: 100%.
  • Add breakpoints with media queries.
