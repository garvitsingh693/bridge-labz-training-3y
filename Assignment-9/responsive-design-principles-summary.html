Responsive Design Principles

Three foundations of flexible web experiences.

Fluid Layouts

Use flexible percentages and sizing functions so layouts adapt to available space.

width: min(100%, 900px);

Flexible Media

Images and videos should shrink within their containers without overflowing.

img { max-width: 100%; height: auto; }

Breakpoints

Media queries adjust layout when the viewport reaches a chosen size.

@media (max-width: 600px) { ... }
Design for content, not just device sizes.
